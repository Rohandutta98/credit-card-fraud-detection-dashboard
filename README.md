# 💳 Real-Time Credit Card Fraud Detection Dashboard

This project is a **Machine Learning-based Fraud Detection System** that identifies suspicious financial transactions and visualizes fraud patterns using an interactive dashboard.

## 🚀 Features

* Fraud detection using **Isolation Forest**
* Interactive **Streamlit Dashboard**
* Fraud analytics visualization
* Fraud risk monitoring
* Real-time transaction analysis

## 📊 Dashboard Components

* Fraudulent Transactions KPI
* Fraud Percentage KPI
* Fraud Amount KPI
* Fraud Location Map
* Fraud Category Analysis
* Fraud Trend by Time
* Fraud Risk Analysis
* Fraud Transaction Table

## 🛠️ Tech Stack

* Python
* Pandas
* Scikit-learn
* Streamlit
* Plotly
* Seaborn

## 📁 Dataset

Credit Card Fraud Detection Dataset
(Anonymized transaction dataset)

## ▶️ Run the Project

Install dependencies:

pip install -r requirements.txt

Run the dashboard:

streamlit run app.py

## 📌 Project Outcome

This system helps financial institutions **detect fraudulent transactions and monitor fraud patterns through an interactive analytics dashboard.**
